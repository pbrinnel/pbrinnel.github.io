Pokémon Conquest League Challenge

An unofficial fan project · work in progress · testers wanted

A browser port of Pokémon Conquest's battle engine with a new single-player roguelite mode: build a squad, climb the map through trainers, wild Pokémon, shops and rests, beat eight Gym leaders, then face the Elite Four and the Champion.

Set up and playYou need your own ROM (see below)

No game files here

This site contains only original code. It contains no ROM, no graphics, no text, no models, no music and no data taken from the game, and it never will. Everything you see in the game is generated inside your own browser from a ROM file that you provide.

  • Browser: a current Chrome or Edge on a desktop is the tested setup. Firefox is not supported yet; phones are untested.
  • Bring your own ROM: Pokémon Conquest, USA / Australia release, Rev 1 (game code VPYT), dumped from a cartridge you own. This site does not tell you where to get one.
  • Your ROM never leaves your device. It is read by a script on the page and never uploaded. There is no server-side code. The one exception to "nothing leaves your browser" is Google Analytics: this site uses it for page views and three milestone events (legal box ticked, build finished, game launched), which contain nothing from your ROM or your game data. No consent banner is shown because no ROM data is involved; block analytics in your browser if you prefer.
  • The data built from your ROM is kept in your browser's storage only, and you can delete it any time from the setup page.

Status of this test build

  • Works now: this page, ROM validation (header, game code, revision, checksum), and the in-browser build of battlefield maps and meshes, Pokémon sprite sheets, text, game data tables and the battle rule tables. A service worker already serves them to the game the way the original tools do.
  • Not yet: the rest of the in-browser build (gimmicks, fonts, HUD and interface art, portraits and stills, battle effects, a few map and sprite formats). The Launch button lists what is still missing and stays disabled until the build is complete, so the single-player mode cannot be started from this site yet.

Developer notes: the playable lab runs locally from the private project today; this deployment is the shell that testers will use once the build is complete.
